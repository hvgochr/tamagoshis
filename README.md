# Tamagoshis

Java console game · University project

A console-based Tamagotchi simulation developed as a university project during my Computer Science degree at IUT Montpellier back in 2023/2024.

Players create and take care of virtual pets, balancing their energy and happiness to keep them alive throughout the game.

## Features

- Randomly generated pets with different behaviors
- Turn-based feeding and playing
- Energy, happiness and aging mechanics
- Survival tracking and final score

## Tech stack

- Java 21
- Gradle 8.5
- JUnit Jupiter 5.10
- Mockito 3.+

## Getting started

```bash
git clone https://github.com/hvgochr/tamagoshis.git
cd tamagoshis

./gradlew run
```

## Running tests

```bash
./gradlew test
```
